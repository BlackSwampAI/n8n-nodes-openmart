The production origin is fixed at `https://api.openmart.ai`, with recommended `Authorization: Bearer <api_key>` authentication. Later operations remain deliberately absent from the node UI.

Safe retrievals use at most three total attempts for HTTP 429, HTTP 500–504, and recognized transient network/timeout failures. `Retry-After` seconds or HTTP dates are honored up to 30 seconds. HTTP 400, 401, 402, 403, 404, and 422 are not retried. Future paid creation requests must select explicit non-retry mode.

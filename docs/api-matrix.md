The production origin is fixed at `https://api.openmart.ai`, with recommended `Authorization: Bearer <api_key>` authentication. Search exposes only `has_website`, `has_valid_website`, `has_contact_info`, and positive-integer `min_locations`; blank location fields are omitted. Tags, other filters, cursors, pagination, and later operations remain deliberately absent.

Safe retrievals use at most three total attempts for HTTP 429, HTTP 500–504, and recognized transient network/timeout failures. `Retry-After` seconds or HTTP dates are honored up to 30 seconds. HTTP 400, 401, 402, 403, 404, and 422 are not retried. Future paid creation requests must select explicit non-retry mode.

For 0.1.0, the shared Batch Status → Task IDs → Task Get retrieval chain and a demonstrated Search → email/contact discovery → downstream data handoff are release-critical, with fixtures and workflow evidence for both branches where appropriate. The node provides data but does not send outreach. Company Emails means generic shared inboxes; Find Decision Makers means named individual contacts and emails.

Future-release/backburner operations, not implemented or advertised, are: Detect Tech Stack; Search Business IDs Fast; Get by Google Place ID; Enrich Company; Enrich Known People; Search Companies; Create Deny Rules; Check Deny Rules; Delete Deny Rules.

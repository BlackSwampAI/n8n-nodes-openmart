# Branding and independence

This is an independent Black Swamp AI community integration and is not affiliated with, endorsed by, sponsored by, or maintained by Openmart. Product names and marks belong to their respective owners and are used only to identify compatibility.

The package uses Openmart's official 256 × 256 color Apple touch icon as a nominative compatibility mark. Openmart declared the asset from its vendor-controlled website as its Apple touch icon when reviewed on September 9, 2026.

The audited source URL is `https://cdn.prod.website-files.com/658be563adc727c27b27070b/67257cc44e06a595780b538d_Frame%208%20(2).png`. The PNG is 256 × 256, 8-bit RGBA, and was copied without redraw, recoloring, cropping, optimization, or any other modification. The square 256-pixel touch icon was selected instead of the wide wordmark or 32-pixel favicon because it fits n8n's compact square node and credential surfaces while retaining the vendor's color artwork. n8n theme metadata requires distinct paths, so the package contains two byte-identical copies of the same unchanged official file; they are not distinct visual variants. Openmart's available official SVG is a wide wordmark unsuitable for a compact square node icon, and neither generated SVG is retained.

This repository's MIT license does not relicense the Openmart trademark asset, and use does not imply affiliation or endorsement. Automated checks cover source registration, inclusion in the packed tarball, and resolution. Visual inspection on contrasting backgrounds in n8n's light and dark editors remains pending. Source files, packed files, the npm README/homepage, and the n8n Creator Portal card are separate surfaces; no Creator Portal card version and logo exist to inspect before publication.
